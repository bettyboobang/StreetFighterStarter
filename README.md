# StreetFighterStarter
Homework for Binary Studio Academy. 

## Завдання
У класі `FighterService` створити метод для отримання детальної інформації про бійця. Додати можливість її перегляду — для цього реалізувати функцію getFighterInfo, яка би опрацьовувала клік по бійцю. Дані відобразити за допомогою функції `createFighterPreview`.
Процес битви буде запускатись за допомогою кнопки `Fight`. У функціїї renderArena викликати функцію `fight` та після закінчення битви вивести переможця на екран за допомогою функції `showWinnerModal`.
Функція `fight` повинна повертати проміс, який буде виконаний успішно, якщо хтось із бійців перемагає.
Гравці наносять удари один одному за допомогою клавіш A (перший боєць) та J (другий боєць). Бійці можуть блокувати удари за допомогою клавіш D та L відповідно, у такому випадку боєць ухиляється від удару. Також боєць не може завдати удар, якщо він знаходиться у блоці.

Показник здоров’я бійця зменшується на кількість шкоди, завданої противником. Її можна буде визначити за допомогою функції `getDamage`, яка повертатиме `getHitPower` — `getBlockPower` (або ж 0, якщо боєць “ухилився” від удару повністю, тобто сила блоку більша за силу удару).

Також завдану шкоду потрібно відобразити за допомогою індикатору здоров’я, який знаходиться над бійцями. Достатньо зменшити ширину елемента health-bar.

Реалізувати функції:

* getHitPower, яка би розраховувала силу удару (кількість завданої шкоди здоров’ю противника) за формулою power = attack * criticalHitChance;, де criticalHitChance — рандомне число від 1 до 2,
getBlockPower, яка би розраховувала силу блоку (амортизація удару противника) за формулою power = defense * dodgeChance;, де dodgeChance — рандомне число від 1 до 2. Не потрібно заокруглювати результати даних функцій.
Бійці також можуть наносити критичні удари, які не можуть бути заблоковані і обчислюються за формулою 2 * attack, де attack — характеристика бійця. Для того, щоб бійцю завдати такий удар, потрібно одночасно натиснути 3 відповідні клавіші, які вказані у файлі controls.js. Цей удар можна наносити не частіше, ніж кожні 10 секунд.
